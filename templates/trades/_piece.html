{% comment %} One licence, in a roster or on the table — the same node either way. It has to be one node, because putting a piece on the table *moves* this element into the dark panel rather than cloning it. Two markups would mean the checkbox that actually submits lives in one of them and the thing you can see lives in the other, which is how a table stops matching the offer it sends. The parent decides which parts show: rosters want a thumbnail, a truncated title and the note; the table wants the full title, the county·year·grade line and a remove control. Expects: `row` (from trades.composer.roster) and `field` — the form field name this side of the table posts to. {% endcomment %}
