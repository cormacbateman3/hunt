Messages · as-built frames (plan_design Pass 9f)

One thread per pair, a room for your collecting buddies, and a watcher that only ever finds.

The 8d Messages frame remains the drawing of record for the two-pane page. These frames record what shipped without a drawing: the room (invite-only group chat) and the moderation funnel behind every message. The forum was deliberately not built — a public surface begs for slop; a private room of collecting buddies is the opposite. Messages stay text only; image sharing in rooms is registered, blocked on the moderation pipeline proving out in production.

The governance, in one line

Any member brings a friend in (the Members popout has the add box); anyone can leave; only the opener can remove somebody — the one quiet power that fixes a bad add without staff. Blocks: you cannot add someone you're blocked with, and a pair block never ejects anyone from a shared room. Caps and the master switch live on MessagingSettings in the admin.

M3

The watcher — the funnel behind every message

apps/moderation · the system finds, humans decide
1 · Watch terms

Admin-editable patterns for the hard signals — minor-safety language, explicit threats. Free, instant, flags only.

2 · Classifier

The free moderation API scores every message within minutes, async, never in the send path. No key? Scans say skipped, never silently clean.

3 · Claude, in context

Only flagged threads. Reads the surrounding messages and judges intent: banter clears, malice surfaces with a one-line rationale. Can clear noise; can never veto an urgent hit.

4 · You

The queue in the admin. Urgent findings page staff immediately, in-app. Resolve, dismiss, hide a message, or reach for enforcement — a human, every time.

What it will never do

Police profanity between friends, haggling, or taking a deal off the platform; punish anybody automatically; block a message from sending. Every tunable — thresholds, category lists, the model, the master switch — is on ModerationSettings in the admin, not in code. Cost at a few hundred users: tiers 1–2 free, tier 3 under a few dollars a month.
